# Obsidian-Daily-Prompt-Generator
Using locally hosted AI, this python script is designed to create daily journal prompts or stories, created into a vault for you!


# Prompt.txt
You will want to create a text file in the same directory you have this script called `prompt.txt`</br>

This is what your prompt to your Ollama instance will actually be

# Vault
The script is set up to create a new folder (directory) inside the directory you have the python script in, titled Vault. This is the Obsidian vault generated from this script. If you would like, you can manipulate this to save the results in your existing vault.
